# Diganta Mandal Portfolio

A personal portfolio for Diganta Mandal, B.Tech CSE (AI & ML) student, built with Next.js and TypeScript.

## Run locally

```bash
pnpm install
pnpm dev
```

## Update content

Portfolio content lives in `app/page.tsx`. Replace the résumé in `public/Diganta_Mandal_Resume.docx` when it changes, keeping the same filename so download links remain valid.
